# 语言练习助手 · Language Practice Assistant

面向 Android 语言练习的辅助实验项目，支持**手动学习、自动作答与本地答案记忆**。通过无障碍节点读取题目，在已适配页面中匹配词语、排列词块、选择选项或填写文字；陌生题可按需使用用户配置的大模型接口。

**非 Duolingo 官方产品。** 请仅在自己的设备及获许可的练习场景中使用，不用于考试代答、刷榜或规避服务限制。使用前阅读 [使用边界](DISCLAIMER.md)、[隐私说明](PRIVACY.md) 和 [安全政策](SECURITY.md)。源码公开可见，原创部分保留权利，未授予开源许可。

## 支持哪些功能

应用提供两种运行模式：

| 模式 | 使用方式 |
| --- | --- |
| 学习模式 | 由你手动作答，助手观察配对或判题反馈，记录符合学习条件的正确答案；不自动点击、提交或暂停 |
| 自动模式 | 优先查询本地词库和已验证答案，按启用的题型作答；陌生题在开启 AI 后请求模型，无法确认时等待手动处理 |

主界面的“自动答题题型开关”包含 **11 个独立选项**，默认全部勾选，修改后需保存。大模型使用另一个独立开关，默认关闭。

| 题型开关 | 当前处理方式与边界 |
| --- | --- |
| 单词配对 | 本地匹配、固定颜色和编号高亮、逐对确认；完整题面只剩唯一一对时可直接尝试配对 |
| 中译英词块组句 / 英译中词块组句（两个开关） | 优先使用已学整句，按当前词块重新定位；陌生句可由模型排列词块 |
| 词义、图片文字选项 | 根据题干与可读文字选项选择；不理解没有文字信息的图片 |
| 填空、补全句子 | 处理已适配的文字选项或输入框布局 |
| 阅读理解 / 对话应答（两个开关） | 使用可访问的文字题干和选项作答 |
| 文字输入翻译 | 只向当前题目内可编辑、非密码输入框填写答案 |
| 其他词块排列 | 按当前可用词块组成答案，校验编号和重复词数量 |
| 听力 / 口语（两个开关） | 仅点击明确的“现在不做听力题”“现在不能说话”等对应按钮；没有按钮时等待手动处理，不识别音频或代为发音 |

这是针对特定无障碍节点布局的测试项目，不是通用答案接口。纯图片题、手写、画线、拖拽、故事特殊交互、音乐/数学及其他未适配布局需要手动处理。项目不使用 OCR。

## 开始使用

1. 按下方构建说明生成并安装应用。首次使用先阅读权限与数据说明，再在系统设置中启用“语言练习助手”无障碍服务。
2. 先选择**学习模式**，在支持的题面中手动答对。只有显示已保存或能在记忆列表中看到记录，才代表学习成功。
3. 在“自动答题题型开关”中选择需要的题型并保存，再启动**自动模式**。关闭的题型等待手动操作。
4. 如需回答陌生题，打开“大模型接口设置”，填写 HTTPS Chat Completions 地址、模型名、密钥和超时，先测试接口，再启用模型开关。接口测试会真实发送示例请求。
5. Android 11+ 启动自动模式时可授权屏幕共享，用于配词状态确认。拒绝或停止共享仍可使用节点支持的自动答题；实际效果受设备、界面与节点可读性影响。
6. 悬浮球可切换“学习 / 自动 / 关闭”。出现接管提示或操作不符合预期时，切换学习模式手动完成，或点击“停止辅助”。

### 学习与本地记忆

- **词对**：支持通用示例词表、手动添加、CSV 导入、手动学习及 AI 补词。导入自己有权使用的 UTF-8 文件，例如 `apple,苹果`；支持逗号、分号或制表符分隔。
- **整句**：保存题干与答对后的词块顺序；重复题按文字重新定位，分词不兼容时重新求解。
- **其他题型**：正确反馈与本次提交关联后保存答案；选项位置改变时按文字匹配。明确判错的答案会被记录，防止同一答案反复提交。

主界面可查看、逐条删除词对、已学整句和其他题型的正确记录。整句及其他题型的模型答案不会仅因模型返回就成为已验证记忆；AI 词对则在候选及冲突校验通过后保存，仍可能有翻译错误。记忆文件保存在应用私有目录，没有单独加密；错答禁用记录目前没有独立管理界面，详见 [隐私说明](PRIVACY.md)。

### 自动确认与接管

配词保留固定高亮、批次点击和独立完成确认；发出点击不等于配对成功。助手综合节点变化、可用的颜色反馈及稳定观察处理动画残留，并对漏点进行有限补试。

组句和其他题型会在每步操作后重新读取题面，检查变化后再提交。计时题遇到陌生题或配词持续无进展时，会按相应策略尝试暂停；暂停需要被实际识别，不能保证所有页面都能暂停。模型请求取消、换题、停止辅助或离开目标应用时会清理相应任务，避免旧答案继续操作新题面。

当布局不完整、模型失败、置信度不足或没有可靠反馈时，程序可能等待或要求接管。高亮、模型自评分和本地格式校验都不能保证答案正确。

## AI、权限与数据

AI 为可选功能，支持兼容 Chat Completions 的 HTTPS 接口。开启后会按题型发送当前候选词，或题干、作答指令、词块/文字选项及编号、输入框数量等信息。不会把截图或整份本地记忆作为请求内容，也不发送已有输入框文字；题目文本本身仍可能包含敏感信息。费用、可用性和数据保留由所选服务商决定。

密钥通过 Android Keystore 加密存储；更换接口域名或端口后不会自动沿用旧密钥。接口不自动跟随重定向。取消请求无法撤回已经到达服务商的数据。

屏幕共享和可用的无障碍截图仅用于本机词卡颜色确认，应用不保存或上传画面。系统捕获范围可能包含其他应用和通知；停止辅助或切换学习模式会停止连续捕获，也可通过系统停止共享。出现“共享已中断”时，可返回助手重新启动自动模式并授权。

## 构建与安装

需要 **JDK 17、Android SDK Platform 36、Build Tools 36.0.0**。最低运行版本为 Android 6.0（API 23）；屏幕共享加速入口要求 Android 11+。Gradle Wrapper 固定为 9.5.0，Android Gradle Plugin 固定为 9.3.0。

```sh
git clone https://github.com/Chandra-VA/wordmatch-assist.git
cd wordmatch-assist
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Windows PowerShell 将 `./gradlew` 替换为 `./gradlew.bat`。通过 `ANDROID_HOME` 或本机 `local.properties` 的 `sdk.dir` 指定 SDK 路径；首次构建需要网络下载依赖。

Debug 安装包位于 `app/build/outputs/apk/debug/app-debug.apk`。它使用本机开发签名，不能保证覆盖其他证书签名的安装包；不要为覆盖安装直接删除重要学习数据。

```sh
./gradlew :app:assembleRelease
```

未配置私有签名时生成 `app-release-unsigned.apk`，签名前不能直接安装。签名配置、代理与可选镜像见 [构建指南](docs/BUILDING.md)。仓库只托管源码、文档和必要测试资源，不包含 APK、API 密钥、签名私钥、本机工具或个人学习记录。

## 项目结构与验证

```text
app/src/main/java/com/wordmatch/assist/
  accessibility/  无障碍扫描、题型分流与自动操作协调
  matching/       词对匹配、批次确认与恢复策略
  learning/       手动配对学习
  sentence/       双向词块组句、正确记忆与错答禁用
  exercise/       多题型识别、独立开关、答案校验与提交学习
  ai/             可选模型请求、响应校验和密钥保护
  capture/        配词状态的连续画面采样
  overlay/        固定高亮、状态和模式控制
app/src/test/     JVM 回归测试及必要的词卡样本
scripts/          源码发布内容检查
.github/          CI、依赖更新和协作模板
```

CI 运行单元测试、Debug 构建和无密钥 Release 构建，不发布安装包。提交前可运行 `python scripts/check_publication.py` 检查已暂存内容；这是有限规则检查，不能代替安全审计。

单元测试覆盖解析、答案协议、状态确认、记忆及恢复逻辑。已有模拟器验证记录见 [CHANGELOG](CHANGELOG.md)；不同课程、系统和应用版本仍需实际验证。部分阅读/对话、文字输入、口语跳过及其他排列布局尚未完成端到端验证，不承诺所有题型或设备可用。
